¿Qué es PequeStudio?

PequeStudio es una aplicación de escritorio para Windows con la que su creador produce animaciones 3D originales (historias, personajes, voces y música propias) y las publica en sus propias cuentas: el canal de YouTube MiniMundos Mágicos y la cuenta de TikTok @mundoanimado.3d8.

La aplicación usa las API oficiales: el creador inicia sesión en la página oficial de cada plataforma y autoriza el acceso (OAuth). PequeStudio nunca solicita ni almacena contraseñas. Cada video se revisa y aprueba manualmente antes de publicarse, y el contenido generado con inteligencia artificial se etiqueta como tal.

What is PequeStudio?

PequeStudio is a Windows desktop application its creator uses to produce original 3D animations (own stories, characters, voices and music) and publish them to the creator's own accounts: the YouTube channel MiniMundos Mágicos and the TikTok account @mundoanimado.3d8.

It uses only official APIs: the creator signs in on each platform's official page and authorizes access (OAuth). PequeStudio never asks for or stores passwords. Every video is reviewed and approved by the creator before publishing, and AI-generated content is labeled as such (TikTok is_aigc, YouTube altered/synthetic disclosure).

TikTok integration: Login Kit (desktop), Content Posting API (upload to the creator's inbox as a draft, or direct post with the creator's chosen privacy after reviewing the creator info), and Display API (the creator's own video statistics shown inside the app).
